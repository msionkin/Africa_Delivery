**Коротко:** 99,99% «для всего» не окупается. Переход с 99,95% на 99,99% стоит около \$0,5M в год, а экономит \$53k простоя в 1-й год. Поэтому SLO задаются по сервисам: оформление заказа и оплата — 99,95%, каталог — 99,9% с кешем в приложении, уведомления — 99,5% за 60 с. SLA для бизнеса установлены ниже SLO. Переход к active-active запланирован по триггеру: когда минута простоя стоит больше \$2,5k, примерно на 3-й год. Шесть из двенадцати видов отказов в FMEA имеют RPN > 100, пять из них — партнёрские интеграции; меры по ним входят в объём работ до 01.10.
